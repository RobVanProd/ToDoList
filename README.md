# ToDoList

ToDoList is an Ionic 3 / Angular 5 starter-style mobile app scaffold from 2018.

## What It Is

The repo contains an Ionic app structure with `src/app`, `src/pages/home`, theme files, service-worker scaffolding, and Ionic build scripts. The homepage still contains starter-style copy, so this should be treated as a learning or template repo rather than a finished app.

## Current Status

The repo defines scripts for `start`, `clean`, `build`, and `lint` through `ionic-app-scripts`. No README was present in the cloned repo.

No local build or test was run for this README.

## Tech Stack

- Ionic 3
- Angular 5
- TypeScript 2.6
- Ionic Native dependencies

## Limitations

This is not portfolio-grade work. Keep it public only as historical/coursework context, or archive it.
